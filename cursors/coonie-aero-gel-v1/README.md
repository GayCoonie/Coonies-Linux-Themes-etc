# Coonie Aero Gel v1

This archive contains:

- `Coonie-Aero-Gel/` — the ready-to-install XCursor theme
- `source-build/` — both generated atlases plus the ImageMagick/Python builder
- `Coonie-Aero-Gel-preview.png` — a quick static contact sheet

## Fast install on Linux Mint 21.3

```bash
cd Coonie-Aero-Gel
./install.sh
```

The installer makes a timestamped backup if a theme with the same name already
exists, installs to your user icon directory, and selects the theme in Cinnamon.
Log out and back in only if an already-open application clings to its old cursor.

You can also install it graphically by copying the `Coonie-Aero-Gel` directory
to `~/.local/share/icons/`, then selecting **Coonie Aero Gel** in **System
Settings → Themes → Mouse Pointer**.
