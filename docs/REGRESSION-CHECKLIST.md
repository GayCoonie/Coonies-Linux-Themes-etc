# Regression Checklist

## Window and widget behavior

- [ ] Focused titlebar buttons are visible and clickable.
- [ ] Windows can be dragged and resized from expected regions.
- [ ] Active titlebars and scroll controls keep the intended purple/multicolor treatment.
- [ ] Colorful gradient glow survives; it has not collapsed into monochrome blue.
- [ ] Menus, dialogs, disabled controls, selections, tooltips, and root-elevated GUI apps remain legible.
- [ ] Belligerent Madness falls through cleanly for missing glyphs.

## Cinnamon shell

- [ ] Panel, menu, calendar, OSD, and tooltips use their intended image-backed surfaces.
- [ ] Battery, Wi-Fi, audio, power, and similar applets use pictorial/full-color assets where requested.
- [ ] CSS does not recolor those assets back into symbolic monochrome.
- [ ] The DarkCold status-area “tiny black coffin” regression is absent.

## Nemo and icons on Mint 21.3

- [ ] Icon view uses sane folder, file, and thumbnail sizes.
- [ ] Compact view uses sane sizes.
- [ ] List view uses sane sizes.
- [ ] Open, visiting, downloads, templates, saved-search, and drag-target folders resolve.
- [ ] Missing icons fall through the intended inheritance chain.
- [ ] No malformed or oversized raster is selected for a small fixed-size request.

## Cursors

- [ ] Pointer, link, text, resize, forbidden, help, drag/drop, and move roles resolve.
- [ ] Hotspots land on the visible interaction point.
- [ ] Busy and progress animations play in order at usable speed.
- [ ] Compatibility aliases resolve to the same intended cursor files.

For visual changes, attach before/after screenshots and record OS, Cinnamon, Nemo, GTK, display scale, and application versions.
