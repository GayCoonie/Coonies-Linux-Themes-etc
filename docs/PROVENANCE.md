# Provenance and Witness Policy

This private working repository preserves several evidence classes together without pretending they are interchangeable:

- **Historical upstream:** DarkCold/SlickCold and donor icon families.
- **Coonie adaptation:** palette, shell behavior, icon selection, aliases, cursor art, and application skins.
- **Generated derivative:** rebuilt theme assets, icon mosaics, cursor binaries, previews, and packages.
- **Maintenance evidence:** audits, checksums, tests, screenshots, histories, and field notes.
- **Current repair:** a bounded change made for a named compatibility failure.

Component-specific licenses and upstream responsibilities remain with their source trees:

- DarkCold: `themes/darkcold-coonie/LICENSE` and `THIRD_PARTY.md`.
- Aero Hoard: `icons/coonie-aero-hoard/LICENSE` and `SOURCE-AND-LICENSES.md`.
- Cursor theme: consult its bundled README/source notes; preserve the original generated masters.
- Belligerent Madness: `themes/darkcold-coonie/assets/fonts/LICENSE-Font-Monkey.txt`.

Do not infer authorship from repository placement. When adding an asset, record its source, transformation, license, and the visual role it was chosen to preserve.
